# Game Modes

The game contains multiple gameplay modes.

## Survival Mode

Current mode.

Features:
- Asteroids movement
- Screen wrapping
- Enemies spawn from screen edges
- Wave progression

## Formation Mode

Unlocked after Survival Wave 3.

Features:
- Fixed player area at bottom of screen
- Enemy formations
- Enemy bombs
- Multi-hit enemies
- Vertical shooter gameplay

Players return to Survival Mode after completion.
